# Additive-Cipher-Automation

"Hello. Our project today is about the Additive Cipher, which is one of the simplest types of substitution ciphers.

The core idea is to shift each character in the plaintext to another character that is a fixed distance away. 

This distance is called the key, and it is represented by $k$."

## Features :
Encrypt & Decrypt:** Secure and retrieve text using key ($k$).
Case Preservation:** Keeps uppercase and lowercase letters unchanged.
File Automation:** Process and encrypt `.txt` files automatically.
Brute-Force:** Crack ciphertexts by testing all 25 keys.
